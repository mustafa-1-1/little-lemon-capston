# Little Lemon Table Booking Application

This project is the Capstone Project for the Meta Front-End Developer Professional Certificate.

## Features
- Interactive table booking form for Little Lemon restaurant.
- Dynamic date and time selection.
- Form validation (min/max guests, required date/time).
- ARIA accessibility attributes included.
- Unit testing with React Testing Library.
